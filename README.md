# Krishna Ravulapati Portfolio

Personal portfolio for Krishna Ravulapati, Staff Site Reliability Engineer focused on cloud reliability, data engineering, automation, and MLOps.

[Live Site](https://krishnaravulapati.github.io/)

## Features
- Modern responsive layout built with Bootstrap 5.3.3 and custom CSS
- Project links for data pipelines, MLOps, and real-time analytics work
- Contact page with verified public profile links instead of placeholder form settings
- Shared styling across Home, About, Projects, and Contact pages
